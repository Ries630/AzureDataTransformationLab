# 会社環境 確認チェックリスト（AWS 0）

このファイルは会社で確認した値を記入するためのものです。**アクセスキー・シークレットキー・セッショントークンなどの認証情報は絶対に書かないでください。** アカウントIDは末尾4桁だけ、ARN全体も書かないでください。

記入したファイルは会社側の手元に置き、リポジトリへコミットしないでください。Codexへは、共有してよい項目だけをチャットで伝えてください。

| 項目 | 値 | AWS版のどこに影響するか |
|---|---|---|
| 利用アカウント（末尾4桁） |  | backend設定・ARN組み立て・対象アカウントの取り違え防止 |
| リージョン |  | provider設定・利用サービスの可用性 |
| 認証方式（SSO / IAMユーザー / その他） |  | 実行主体の扱いとplan/applyの認証手順 |
| 命名規則 |  | リソース名（S3バケット等のグローバル一意制約を含む） |
| 必須タグ |  | default_tags・リソースタグの設定 |
| 利用期限 |  | 削除計画・ライフサイクル設定 |
| 予算 |  | 実機検証の回数・残すリソースの範囲 |
| 通知先メール（SNS購読先） |  | 通知トピックの購読設定 |
| Terraform state の保存先（会社提供のS3 bucket・DynamoDBロックの有無、または自分で作成可） |  | backend設定を誰が用意するか |
| 既存のKMSキー指定の有無 |  | 暗号化を既存キー参照にするか新規作成にするか |
| ファイル転送方法 |  | ZIPの持ち込み経路（共有フォルダ・許可された媒体など） |
| 会社PCのOS・CPU | Windows（CPU: 要確認） | Provider・配置物のアーキテクチャ選択 |
| Provider取得可否（terraform initの結果） |  | Provider mirror 持ち込みの要否 |
| 管理者に依頼する権限（denied_actions から転記） |  | 自分で作る範囲と依頼範囲の切り分け |
