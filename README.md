# Azure Data Transformation Lab

仕事で予定されているAWSベースのデータ変換層を理解するため、Azure上に概念的に対応する個人学習環境を構築する。

Azureサービスの習得自体ではなく、イベント駆動、オーケストレーション、入力検証、スキーマ変化、ETL、監視、冪等性を実装してAWS構成への理解を深めることが目的である。
